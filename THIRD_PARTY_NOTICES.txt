NOTE FOR MAINTAINERS: This list is maintained by hand and should be regenerated
authoritatively before each release with a tool such as `go-licenses`:

    go install github.com/google/go-licenses@latest
    go-licenses save   ./cmd/fv-ssh-unlock --save_path=dist/licenses            # default build
    go-licenses save   ./cmd/fv-ssh-unlock --save_path=dist/licenses-keyring \
        --ignore ""    # with GOFLAGS=-tags=keyring for the keyring backend
    go-licenses report ./cmd/fv-ssh-unlock

Run once with the default build tags and once with `-tags keyring`, since the
keyring credential backend pulls in additional dependencies.
